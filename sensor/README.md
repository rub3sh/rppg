# Contact PPG reference — XIAO ESP32-C3

Wiring, build and logging notes live in the project chat. Quick reference:

| Sensor pin | XIAO pin | GPIO | Note |
|---|---|---|---|
| Signal (S / A0) | D1 | GPIO3 | ADC1_CH3, not a strapping pin |
| VCC (+) | 3V3 | — | 3.3 V only, never 5 V |
| GND (−) | GND | — | |

| OLED pin | XIAO pin | GPIO |
|---|---|---|
| SDA | D4 | GPIO6 |
| SCL | D5 | GPIO7 |
| VCC | 3V3 | — |
| GND | GND | — |
